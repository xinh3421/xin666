# 开发与验证指南

根目录 index.html 是完整应用，包含样式、TodoCore 数据逻辑和界面事件。单文件使下载、离线打开和静态托管一致。新增功能直接修改该文件；src/README.md 记录此约定。

## 启动

双击 index.html 即可。或使用 Node.js 22+ 执行 `node scripts/serve.cjs`，访问 http://127.0.0.1:4173；Ctrl+C 停止。服务仅返回应用页面，不读取其他任意路径。无安装、配置或构建步骤。

## 自动化检查

运行 `node --test tests/core.test.cjs`。测试从实际 HTML 中提取 TodoCore，验证输入、持久化、完成状态、编辑删除结果、组合筛选、JSON 往返及损坏数据与存储失败。

## 浏览器验收

1. 首次打开为空；添加任务、输入空白并确认有反馈。
2. 编辑任务、标记完成，使用状态筛选与搜索。
3. 刷新，确认任务内容与状态保留。
4. 导出 JSON，删除任务，再导入备份恢复。取消导入确认不改变数据。
5. 导入损坏 JSON，确认原清单不变且显示失败原因。
6. 删除单项、清理已完成任务；取消确认应保留数据。
7. 在窄屏检查布局，使用 Tab 和回车操作表单，Esc 关闭编辑窗口。

任务文本通过 textContent 显示，不作为 HTML 执行。持久化成功后才更新内存及界面。存储损坏时暂停写入；通过有效备份恢复。数据不上传；不同地址、浏览器和文件路径的存储独立。多标签页通过 storage 事件更新；同时编辑以最后一次保存为准。
