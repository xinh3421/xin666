# 项目说明

## 首个可用版本

目标用户：需要简单记录个人事项、希望无需注册即可使用的人。

核心问题：把零散事项整理成可完成、可搜索、可备份的清单。

输入：1–200 字的任务内容。输出：显示在清单中，可编辑、完成或删除；刷新后从本地存储恢复。

验收示例：输入“整理书桌”并添加，清单出现同名任务；勾选后进入“已完成”；刷新仍保留状态；导出 JSON 后可以导入还原。

技术选择：原生 HTML、CSS、JavaScript 单文件；无第三方依赖、无构建、无服务器业务。Node.js 22+ 仅用于测试和可选预览。数据采用带 version=1 的 JSON，存储键为 xin666.tasks.v1。

限制：单浏览器本地保存；最多 10000 条任务；不提供账号、跨设备同步、协作或提醒。JSON 导入最大 10 MB，需确认后替换现有清单。未选择开源许可证。
