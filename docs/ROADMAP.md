# 开发路线

## v0.1 当前版本

- [x] 离线单文件应用与响应式中文界面。
- [x] 任务新增、编辑、完成、删除及清理已完成。
- [x] 状态筛选、搜索、进度与空状态。
- [x] 本地保存与刷新恢复。
- [x] JSON 备份导入导出、格式校验与保存失败反馈。
- [x] Node 内置测试、预览服务、运行与验证说明。

## 后续开发入口

每次从一个可验收任务开始，按使用反馈决定优先级：

- [ ] 任务截止日期与排序：提供明确日期输入和过期显示示例。
- [ ] 分类标签：定义标签增删、组合筛选与备份兼容方式。
- [ ] 自动化浏览器回归检查：覆盖实际下载与文件导入。
- [ ] 发布流程与许可证：由维护者选择托管平台和许可证。

账号与跨设备同步需要新的数据和身份方案，暂不纳入当前版本。
